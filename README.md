## 1. Project Description

This project implements a stack-based mathematical expression evaluator using Python. The program reads mathematical expressions from an input file, evaluates them using a stack data structure, and saves the results in an output file.

## 2. Objectives

- Implement a stack data structure using Python.
- Perform stack operations such as push, pop, and peek.
- Evaluate mathematical expressions using stacks.
- Support addition, subtraction, multiplication, and division.
- Handle parentheses and operator precedence.
- Read expressions from input.txt and save results in output.txt.
- Handle invalid expressions and division by zero.

## 4. Project Files

- `main.py`: Contains the Python source code.
- `input.txt`: Contains the mathematical expressions.
- `output.txt`: Stores the calculated results.
- `README.md`: Provides project documentation.

## 5. How to Run the Program

1. Install Python on your computer.
2. Open the project folder in Visual Studio Code.
3. Ensure that `main.py` and `input.txt` are in the same folder.
4. Open the terminal in Visual Studio Code.
5. Run the following command:

   `python main.py`

6. Open `output.txt` to view the results.
